# SWYNEX Final Data Analytics Project

## Project Overview
This project presents a complete data analytics workflow using sales data. The project covers data understanding, data cleaning, analysis, visualization, and business insights.

## Problem Statement
The objective of this project is to analyze sales data and identify useful patterns and insights related to sales performance across different cities and categories.

## Dataset
The project uses sales data provided for analysis.

Files included:
- `sales_data_raw.xlsx` - Original raw dataset
- `sales_data_cleaned (4).xlsx` - Cleaned dataset
- `task 3.pbix` - Power BI dashboard

## Data Cleaning
The dataset was reviewed and cleaned before analysis. The cleaning process included:
- Checking the dataset structure
- Handling data inconsistencies
- Cleaning and organizing relevant fields
- Preparing the data for analysis and visualization

## Analysis
The cleaned data was analyzed to understand sales performance and identify patterns in the dataset.

## Power BI Dashboard
A Power BI dashboard was created to visualize sales performance and provide an easy-to-understand view of the data.

The dashboard includes visual analysis of sales across different cities and other relevant dimensions.

## Key Business Insights
- Sales performance varies across different cities.
- The dashboard helps identify areas with higher and lower sales performance.
- Visual analysis makes it easier to compare sales across different categories.
- The analysis can support data-driven business decisions.

## Tools Used
- Microsoft Excel
- Power BI
- GitHub

## Project Outcome
This project demonstrates the complete data analytics workflow from raw data to cleaned data, analysis, visualization, and business insights.
